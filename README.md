# Marlow Ridge Site Starter

A small Jekyll-compatible starter for Marlow Ridge Research project sites.

## What is in this starter

- `_config.yml` - site title, description, and navigation
- `index.md` - home page
- `publications.md` - publications landing page
- `_layouts/default.html` - base HTML layout
- `assets/css/site.css` - base styles
- `VERSION` - starter release marker

## Making a project site

Create a new repository for the project and mirror these files unchanged. Adjust the
`title` and `description` values in `_config.yml` for the project, and replace the
placeholder copy on the pages with project content. Do not edit the layout or the
styles here; those are owned by the design system.

Starter release: see `VERSION`.
